What one transaction does

The model has 5 layers. Each transaction computes exactly one of them for the current token position, then writes the residual stream and that layer's KV cache back to storage. A sixth transaction runs the classifier and emits the token. So one token = 6 transactions.

Signing key & contract

Approving six transactions per token by hand is unusable, so a throwaway key is created in this page, funded by your single approval, and signs every step. It is kept in this browser only (so leftover funds stay recoverable after a reload) and never transmitted. Testnet only — never import a key with real funds.
